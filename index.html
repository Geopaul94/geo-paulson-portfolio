01 / ABOUT

Mobile engineer, product builder,

I'm a Software Engineer focused on Flutter and cross-platform mobile development. At Laennec AI, I build and maintain production applications using Flutter, native Android with Kotlin and Jetpack Compose, and iOS with Swift and Xcode.

I work across the product lifecycle: translating requirements into technical solutions, building features, integrating APIs, testing, debugging and preparing releases. My backend and cloud work includes Python Flask, Firebase and Google Cloud, with GitHub Actions supporting repeatable builds and releases.

Beyond my professional work, I independently build, publish and maintain mobile products. These include Debt Tracker, a personal finance app, Klik, a real-time social application, and the Ultimate Pet Lover’s App.

I use OpenAI Codex and Claude Code throughout implementation, debugging, refactoring and testing, while personally owning technical decisions and final product quality.
